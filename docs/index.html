CROSS-SECTION ANALYSIS

表达一致性与图像消融

比较层表达模式、空间梯度、邻域关系，以及图像特征的预测增益。

白质模式一致，皮层仍有差异

2,000 个基因的层对比中，七类有六类与另一切片的同名层最相关。白质相关系数为 0.916，L6 为 0.296。

开发片筛选的 21 个候选在留出片均保持正方向。这是同供体相邻切片的方向复核，不能替代独立供体验证。
